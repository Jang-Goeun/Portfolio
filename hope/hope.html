희망 연구소의 비밀

클라이언트 개발 (Client Developer)

GitHub Play Store

프로젝트 소개

"평소처럼 야근하던 어느 날, 비상 알림음에 사무실에서 눈을 뜬 연구원. 시끄러운 복도로 나가자 마주친 건 동료들의 시체와 자신을 향해 달려오는 끔찍한 괴생명체들. 이로부터 도망치며 연구소의 진실을 알아내야 한다!"

개발 기간 2024.02.21 ~ 2024.02.28 (해커톤)
인원 구성 기획 1, 디자인 1, 기획/디자인 1, 개발 4
기술 스택
C# Unity

메인 타이틀 스크린

나의 역할 및 기여도 (30%)

핵심 게임 시스템 & 연출

  • • 게임 시작 및 게임 오버 화면 UI 및 전반적인 흐름 로직 구현
  • • Json을 활용한 게임 진행 상태 저장 (Persistence) 시스템
  • • 캐릭터 애니메이션 상태 전이(State Machine) 설계
  • • 게임의 깊이를 더하는 연구일지 시스템 구현

미니게임 개발

  • • 카드 뒤집기 미니게임의 알고리즘 및 로직 설계
  • • Random 클래스를 활용한 매 게임 새로운 카드 랜덤 배치
  • • 카드 프리팹(Prefab)화를 통한 효율적인 재사용 및 관리
  • • Invoke를 활용하여 카드 뒤집기 동작에 적절한 시간 지연(Delay) 연출 추가
  • • [SerializeField]를 활용해 Inspector 창에서 변수 값을 조절하며 게임 난이도 및 연출 최적화

시연 영상

"희망 연구소의 비밀" 실제 플레이 및 기능 시연 영상

게임 상세 소개

01. 몰입되는 스토리

긴박한 아포칼립스 세계관과 캐릭터 간의 대화를 통한 내러티브 전달

02. 전투 플레이

연구소 내부의 기괴한 몬스터들과의 실시간 교전 시스템

03. 보스 피하기

추격해오는 강력한 보스를 피해 동료를 구출하고 탈출하는 긴장감

04. 미니게임 (전력 복구)

카드 뒤집기 퍼즐을 통해 시설을 가동하고 스토리를 진행하는 요소

05. 세계관 비주얼

픽셀 아트로 구현된 공포스러운 연구소 분위기와 독특한 캐릭터 디자인

어려움 (Challenges)

유니티 첫 도전: 개발진 모두 유니티 경험이 없는 상태에서 1주일이라는 짧은 해커톤 기간 내에 엔진 습득과 개발을 동시에 완료해야 했습니다.

극복 과정 (Problem Solving)

빠른 언어 전환 학습

기존 C 언어 지식을 바탕으로 C#과 유니티를 병행 학습하여 초기 런닝 커브를 최소화하고 바로 개발에 착수했습니다.

긴밀한 실시간 피드백

디스코드를 통해 팀원들과 실시간으로 소통하며 문제 상황을 즉각 공유하고 함께 해결하여 개발 효율을 극대화했습니다.
